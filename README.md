# 星际公民数据

数据源：UEX（uexcorp.space）公开 API v2。以 LLM 工具形式提供：

- `sc_ship_info`：飞船/载具参数（船员、货舱、尺寸、燃料、定位）
- `sc_commodity_info`：商品参考均价与类型
- `sc_commodity_prices`：各终端实时买卖价（哪里买最省、卖给哪里最赚）

群里直接自然提问即可（“北极星号参数”“农业素多少钱”“Agricium 卖哪里”），模型会
把中文翻译成英文名调用工具。商品名和飞船名以英文名为准（游戏内原名）。

缓存：飞船/终端 24 小时、商品 6 小时、终端实时价 30 分钟，避免频繁请求 UEX。
